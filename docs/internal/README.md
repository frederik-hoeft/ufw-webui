# Internal Maintainer Notes

`docs/internal` is non-normative working space for unresolved product/design work that is not yet part of UFWeb's steady-state contract.

Use this directory for questions or backlog items that still need a dedicated design/implementation decision. Do not keep completed sprint plans, refactor checklists, validation logs, or descriptions of behavior that already exists. Once work reaches the approved baseline, move its durable contracts into the appropriate architecture, protocol, deployment, development, or testing document and delete the temporary plan.

The current unresolved design backlog is tracked in [backlog.md](backlog.md).
