# UFW Console brand assets

These are the approved source assets for the UFW Console application mark.

- `cleaned-close-3-gradient.svg` is the primary in-product mark.
- `cleaned-close-3-currentcolor.svg` is the monochrome/current-color variant.
- `cleaned-close-3-flat.svg` is the flat-color variant.
- `cleaned-close-3-app-icon.svg` is the application/favicon treatment.
- The PNG files are raster exports of the gradient mark at common sizes.

Runtime copies needed by the Blazor client live under `src/Ufw.Client/wwwroot/brand/`.
