# UFWeb brand assets

These are the approved source assets for the UFWeb application mark.

- `ufweb-mark.svg` is the primary transparent gradient mark.
- `ufweb-mark-currentcolor.svg` is the monochrome/current-color variant.
- `ufweb-mark-flat.svg` is the flat-color variant.
- `ufweb-app-icon.svg` is the application/favicon treatment.
- `ufweb-mark-{32,64,128,256}.png` are raster exports of the primary mark.

Runtime copies needed by the Blazor client live under `src/Ufw.Web.Client/wwwroot/brand/`.
