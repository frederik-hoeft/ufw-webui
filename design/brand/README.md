# UFW Console brand assets

These are the approved source assets for the UFW Console application mark.

- `ufw-console-mark.svg` is the primary transparent gradient mark.
- `ufw-console-mark-currentcolor.svg` is the monochrome/current-color variant.
- `ufw-console-mark-flat.svg` is the flat-color variant.
- `ufw-console-app-icon.svg` is the application/favicon treatment.
- `ufw-console-mark-{32,64,128,256}.png` are raster exports of the primary mark.

Runtime copies needed by the Blazor client live under `src/Ufw.Client/wwwroot/brand/`.
